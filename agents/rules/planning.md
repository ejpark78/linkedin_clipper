## 📋 Planning Rule

> [!IMPORTANT]
> 계획서는 **한국어**로 작성합니다.

### 1. 계획 수립
* 작업 전 Plan을 수립하여 사용자에게 제시합니다.
* 복잡한 작업의 경우 Gitea 이슈를 생성해 추적할 수 있습니다 (선택 사항).
* 생성된 이슈가 있다면 웹 링크를 공유하고 작업 승인을 받습니다.

### 2. 사용자 승인
* 승인이 떨어지기 전까지 소스 코드나 설정을 수정하지 않습니다.

### 3. 자율 실행
* 승인 후 단일 턴 내에서 계획된 작업을 일괄 처리합니다.
* 완료 후 `git add -A && git commit -m "<type>: <description>" && git push`로 커밋합니다.
* Gitea 이슈가 있다면 댓글을 남기고 종료 처리합니다.
